## 候選項目卡片

### 1. Mirage (strukto-ai/mirage)
- **類別**: Infrastructure / VFS
- **亮點**: 為 AI Agent 打造的統一虛擬檔案系統。支援 FUSE、TypeScript、Python。
- **蝦家班評估**: 
    - **借鏡**: 其 VFS 抽象層可作為我們處理跨環境 (Firebase/GCP VM/Local) 檔案訪問的參考。
    - **二創**: 或可封裝成一個 OpenClaw Skill，讓子代理能透明地存取不同維度的資源。
- **URL**: https://github.com/strukto-ai/mirage

### 2. Awesome Agentic AI 中文版 (WenyuChiou/awesome-agentic-ai-zh)
- **類別**: Learning / Roadmap
- **亮點**: 結構化的 AI Agent 學習路徑，包含 MCP (Model Context Protocol) 與 Claude Code 的實作指南。
- **蝦家班評估**: 
    - **避坑**: 裡面提到的 MCP 實踐與我們目前的 `mcporter` 工具鏈可以互相對照，檢查是否有未考慮到的安全配置。
    - **部署**: 可將其推薦的優質 MCP Server 納入我們的工具庫。
- **URL**: https://github.com/WenyuChiou/awesome-agentic-ai-zh

### 3. AiSOC (beenuar/AiSOC)
- **類別**: Security / Automation
- **亮點**: 開源的 AI 驅動安全營運中心，支援 Agent 輔助的分流 (Triage) 與調查。
- **蝦家班評估**: 
    - **部署**: 適合部署在 Staging 環境，用來監控我們多個 Gateway 的調用異常與防禦攻擊。
    - **二創**: 其「警報融合 (Alert Fusion)」邏輯可以整合進 `9router` 的防禦策略中。
- **URL**: https://github.com/beenuar/AiSOC

### 4. TQ-Trading-Agent (TQ-trade-agent/tq-trading-agent)
- **類別**: Application / Finance
- **亮點**: 使用 LangGraph 與 TypeScript 實現的多代理股票研究與交易編排。
- **蝦家班評估**: 
    - **二創**: 雖然是交易機器人，但其 **Multi-Agent Orchestration** 的架構（LangGraph 實作）對我們發展 `clawteam` 的協作邏輯有極高參考價值。
- **URL**: https://github.com/TQ-trade-agent/tq-trading-agent

### 5. Agent-Skills-Eval (darkrishabh/agent-skills-eval)
- **類別**: Tooling / QA
- **亮點**: 針對 agentskills.io 風格技能的測試運行器。
- **蝦家班評估**: 
    - **部署**: 直接與我們的 `qa-testing` 技能整合。我們目前的測試較為人工，這個工具可以實現 Skill 層級的自動化單元測試。
- **URL**: https://github.com/darkrishabh/agent-skills-eval
