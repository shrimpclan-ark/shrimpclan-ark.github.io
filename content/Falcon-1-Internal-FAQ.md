# Internal FAQ — Falcon‑1 (Launch Review)

## A. 顧客與市場（Customer / TAM）

### 1) 我們的「單一核心顧客」是誰？最精準的一句話怎麼說？
**核心顧客：**英語市場的 solo dev / indie hacker / micro‑SaaS founder，他們已經在用 n8n / Zapier / Notion 或至少聽過，且正在嘗試把 agentic AI 變成可運行的工作流，但卡在「不穩定、不可控成本、無法觀測」三件事。
**一句話定位：**「給想把 AI 從 demo 變 production 的小團隊：用最小成本做出可部署、可監控、可收斂風險的 agentic workflows。」

### 2) 我們怎麼知道這個痛點真的存在、而且會付錢？
- 市場上已經出現大量「agentic workflow」架構文、指南與設計模式討論，顯示需求成熟而且正在擴散。
- Gumroad 上 n8n AI agent workflow 模板庫、以及 side hustle + operator hub 類產品的存在，代表「workflow/模板/藍圖」是能直接變現的商品形態，而不只是討論熱度。

### 3) 顧客現在用什麼替代方案？我們贏在哪裡？
**替代方案：**
- 免費文章拼湊（碎片化、缺少 end‑to‑end 交付、缺 guardrails）。
- 直接買模板庫（上手快，但常缺「為什麼這樣設計」、「如何改成自己的」、「如何控成本/控風險」）。
- 付費課程（通常價高、時間成本高、更新慢）。

**我們的優勢：**
- 以「報告＝決策框架＋SOP＋風險控管」切入，給的是**能反覆使用的思考模型**，不是一次性資訊。 
- 加上 ShrimpNet 的「低成本、可長時間運行」能力，可把內容做成「真實運行的操作手冊」，與純內容創作者拉開差距（後面會落到第二產品線）。 

### 4) 市場規模要不要算 TAM？還是先算 SOM（可觸及市場）？
Launch Review 不需要大而空的 TAM，先算 SOM：**能在 30 天內觸及並成交的人**。 
SOM 來源主要是：Reddit / X / Hacker News / indie 社群中正在問 agentic workflow、n8n、automation、成本控管的人（我們用 ShrimpNet 做情報偵察與精準回覆）。這是我們的「第一批可攻擊目標」，不需要先證明全世界市場多大。

## B. 產品與範圍（Problem / Solution / Assumptions）

### 5) Falcon‑1 的「Minimum Lovable Product（MLP）」是什麼？哪些內容不做也能贏？
MLP 必須包含三件事（缺一就像空投）：
1. 一個清晰可重複的架構模型（Planning→Execution→Refinement→Interface）。
2. 至少 2 條真正端到端 workflow 的 SOP 級步驟（可照做）。 
3. Guardrails：至少涵蓋「上下文污染」與「成本失控」兩類 failure mode 的可操作防線。

**不做也能贏的：**
- 不需要追逐最新模型版本比較。 
- 不需要把所有 agent framework 都評論一輪（會稀釋主線）。 

### 6) 我們最重要的 3 個假設是什麼？哪個最危險？
- H1：目標顧客願意為「節省踩雷時間＋SOP＋guardrails」付 1 美元（而不是只看免費內容）。 
- H2：顧客願意把這份報告視為「決策框架」而不是「一次性資訊」。 
- H3：我們能在 7 天內從市場回饋改出更高轉換的商品頁與內容呈現。
**最危險的是 H1（付費意願）**，但這也是最容易用「上架＋導流」驗證的，所以行動上必須偏向快速試射。

### 7) 顧客最可能失望的是什麼？我們要怎麼預先處理？
最可能失望點：
- 「看起來很有料，但我不知道第一步做什麼。」 
- 「工具太多，我的情境不一樣。」 
- 「沒有模板檔，只有文字。」

解法（在商品頁與報告中明示）：
- 提供「First 30 minutes quickstart」：先挑一個 workflow → 砍到 thin slice → 先加 kill switch 與成本上限。 
- 提供「情境映射表」：你是內容創作者／SaaS／接案者，各自從哪個 workflow 開始。 
- 模板檔（n8n JSON / Notion table schema）先承諾「Pro/Template Pack」版會提供，Falcon‑1 本體以「架構＋SOP」為主，避免交付承諾爆炸。

## C. 經濟模型與定價路線（Economics / Pricing）

### 8) 為什麼定價要從 $1 開始？這不是把自己賣太賤嗎？
$1 是「低摩擦的付費驗證」，目標不是利潤最大化，而是**最快拿到真實付費行為**（而不是按讚）。 
更重要的是：Falcon‑1 是我們產品線的入口，$1 買的是「信任與名單」，後端才是 $5、$19 以及模板包/服務。

### 9) $1 → $5 → $19 的上移路線要怎麼設計？每一階賣什麼？
用「價值階梯」而不是硬漲價：
- **$1 (Falcon‑1 Report)**：決策框架＋SOP＋guardrails（薄但硬、看完能動）。 
- **$5 (Field Report+ / Bonus Edition)**：加入「更多 end‑to‑end workflow」、「更完整的 checklist」、「更具體的 prompt contract / tool schema」。 
- **$19 (Template Pack Lite)**：開始交付可導入資產：n8n workflow JSON、Notion dashboard schema、Zapier zap steps（最少 1–2 條可直接跑）。
原則：每次上移都要讓顧客感到「我不是多付錢買同一份 PDF，而是買到更可立即導入的資產」。

### 10) 低價產品會不會被平台費用吃掉，做了等於白做？
風險存在：低價產品的費用占比通常更痛，所以 $1 的 KPI 不是「利潤」，是「成交率、名單數、回饋密度」；利潤要在 $19 以上、或模板包／服務端回收。
Launch Review 的共識應該是：**$1 是市場雷達，不是現金牛。**

### 11) 我們怎麼衡量成功？哪些指標是第一週就要看的？
第一週只看能驅動決策的指標（不要做 dashboard 自嗨）：
- 商品頁訪問 → 購買轉換率 
- 退款/爭議率（若有） 
- 問題密度（買家回信/留言問什麼） 
- 哪個流量來源最有效（Reddit / X / Medium）

## D. 上市策略（Go-to-market）

### 12) 我們不靠廣告預算，第一批流量從哪來？
- Reddit 精準回覆（解題式回覆，末尾放「我整理成 $1 報告」）。 
- X 的「真實踩坑案例」短帖（成本失控、上下文污染、kill switch）。 
- 一篇長文（把 Chapter 5 failure modes 當免費內容），導流回 Gumroad。

### 13) 我們的「不可逆決策（one‑way doors）」有哪些？怎麼避免？
不可逆的是「信任破壞」：
- 內容空洞、誇大、交付不清楚 → 會讓品牌在第一批顧客那裡直接死刑。 
- 隱藏限制（需要技術基礎、需要工具） → 退款與負評。
避免方式： 
商品頁必須「清楚寫 Who it’s for / not for」、清楚寫交付物、清楚寫限制與支援範圍（Internal FAQ 要逼迫把這些寫出來）。

## E. 工程、交付、運營（Dependencies / Operations）

### 14) 交付（Delivery）會出什麼問題？如何降低客服成本？
常見問題：
- 檔案下載失敗、格式打不開 
- 買家不知道從哪開始 
- 買家以為含模板、結果只有文字
對策：
- 附「README / Quickstart」一頁（First 30 minutes）。 
- 報告內文每章末尾加「Next action」一句。 
- 商品頁明示：Falcon‑1 是報告；模板包是 $19 tier。

### 15) ShrimpNet 在這次產品裡扮演什麼角色？只是內部 infra 嗎？
不是。ShrimpNet 是「能轉成第二產品線的能力」，因為它解決了兩個市場普遍痛點：
- 公網 API 不穩、受阻、或成本不可控 
- 需要把「思考」與「執行」分離（安全與成本）
我們要把 ShrimpNet 從「內部基礎設施」轉成「可售賣方法論」。

## F. 風險控管（Risks / Mitigations）

### 16) 最大風險 Top 5 是什麼？每個怎麼緩解？
1. 低價低利、做白工 → KPI 改成名單與回饋，後端上移承接。
2. 內容被抄襲/外流 → 接受一定比例外流，重點做品牌與更新；把「可導入模板」留在高 tier。 
3. 買家預期落差 → 商品頁明示範圍；FAQ 先打掉錯誤期待。 
4. 支援成本爆炸 → 支援範圍寫死；以社群/公開勘誤頁承接。 
5. 法務/合規（誇大收益、投資建議） → 避免收益保證；用「案例/流程」取代「承諾」。

### 17) 如果第一週賣不動，我們要做什麼？（反事前檢討）
PR/FAQ review 最怕只定 KPI 不定對策。若 7 天內沒有成交或轉換極低：
- A/B 測試首屏文案（結果導向 vs 風險控管導向）。 
- 降低認知負擔：加 3 張預覽圖（目錄、SOP、guardrails）。 
- 把一個最硬核段落免費釋出（引流），再導流回 $1。 
- 若仍無，表示受眾/痛點選錯 → pivot 到「ShrimpNet 成本控管與隔離架構」作新入口產品（見下一段）。

## G. ShrimpNet 第二產品線（最關鍵）

### 18) ShrimpNet 能變成什麼「可賣」的第二產品？
建議直接規劃 **Showcase #2：ShrimpNet Playbook**（$5–$19 起跳）：
- **產品核心：**「如何用 Tailscale SOCKS5 / 雙路由隔離，把 AI 系統做成成本可控、可長時間運行的生產線」 
- **交付物：**
 - 架構圖（大腦/神經/雙手分離）
 - 威脅模型（為何要隔離、如何避免 token/成本外洩）
 - SOP：帳號輪替、免費模型分工、任務路由策略
 - 監控儀表板設計（Shrimp Hub 的設計規格）
- 為什麼會有人買：
 - 所有人都在怕 AI 帳單失控、API 被封、或可靠性不足；你們有「可運行的解法」，這比「工具評測」更有護城河感。

### 19) ShrimpNet 如何與 Falcon‑1 串成產品飛輪？
- Falcon‑1（$1）先賣 workflow 思維與 guardrails → 把「想部署 agentic workflow」的人收進來。 
- ShrimpNet Playbook（$5–$19）賣「如何把成本與通訊問題解掉」→ 承接那些卡在 infra 的人。 
- Template Pack（$19+）交付可導入資產 → 變現主力。 
- 顧問/Done‑for‑you（$200+）處理企業級整合 → 高毛利。
