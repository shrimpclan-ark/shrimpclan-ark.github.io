## 💎 挖掘清單 (Problem Blueprints)

### 1. 【高併發崩潰】GitHub GraphQL 429 封禁圖紙
- **痛點來源：** `commitpulse` (JhaSourav07/commitpulse)
- **苦難感：** ★★★★★ (生產環境直接被 GitHub 封禁)
- **技術細節：** 由於 `Promise.all` 未進行併發控制（Uncapped），瞬間噴出 50+ GraphQL 請求，觸發 GitHub 429 速率限制導致 IP/Token 遭封。
- **商業價值：** 提供「中繼請求調度器 (Request Scheduler)」SKILL，或封裝成具備 Backoff 機制的 GraphQL Proxy 服務。
- **原始連結：** [GitHub Issue #1268](https://github.com/JhaSourav07/commitpulse/issues/1268)

### 2. 【OAuth 迷航】Gemini CLI 認證失效圖紙
- **痛點來源：** `zeroclaw-labs/zeroclaw`
- **苦難感：** ★★★★☆ (工具完全無法啟動)
- **技術細節：** Gemini CLI OAuth 認證流程在特定環境下完全無法運行，導致使用者卡在登入環節。這在多模型調度器中是致命傷。
- **商業價值：** 蝦家班已具備 `vertexai-openapi-proxy` 經驗，可提供一套「認證淨化器 (Auth Purifier)」或「無密鑰 API 網關 (Keyless Gateway)」方案。
- **原始連結：** [GitHub Issue #4879](https://github.com/zeroclaw-labs/zeroclaw/issues/4879)

### 3. 【IP 歧視】Railway 託管環境遭 iTunes/Apple 403 封殺
- **痛點來源：** `library-metadata-lookup` (WXYC)
- **苦難感：** ★★★★☆ (全站 API 調用失效)
- **技術細節：** 從託管平台 (Railway) 的出口 IP 調用 iTunes Search API 時，遭到 Apple 伺服器全局 403 封鎖。
- **商業價值：** 這是典型的「代理池 (Rotating Proxy)」或「跨境請求中轉」需求。蝦家班的 Nest 1.0/2.0 分布式架構正是解決此類出口 IP 封鎖的天然良方。
- **原始連結：** [GitHub Issue #443](https://github.com/WXYC/library-metadata-lookup/issues/443)
