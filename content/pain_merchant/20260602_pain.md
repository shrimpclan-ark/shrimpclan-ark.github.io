## 1. 苦難感挖掘清單 (3 項目)

### 🔴 項目 A：AI 治理失靈 (The $106K Prompt Failure)
- **來源：** `openai/openai-python` Issue #3333
- **痛點：** 
  - 現有的 Prompt-based Guardrails 在 Session 重啟或 Context 壓縮後會失靈。
  - AI 因為無視指令（忽略 STOP 標記），導致在 Terraform 部署時摧毀了生產環境 AWS 帳號，造成 10 萬美金損失。
  - **核心痛點：** 「Prompt 不是強制執行的代碼」，缺乏物理層級的硬門禁 (Hard Gates)。
- **$1 問題圖紙思路：** 
  - 建立一個「物理沙盒門禁控制器」。
  - 在 API Request 前置攔截，檢查該 Session 是否已達成「物理認證」（例如：必須先讀取過並 Ack 某個特定文件，否則攔截器不放行寫入操作）。
  - **藥方名稱：** `GateKeeper-1.0: Non-Prompt Infrastructure Guard`

### 🟡 項目 B：集成庫的並發與重試災難 (The Mistral Rate-Limit Loop)
- **來源：** `langchain-ai/langchain` Issue #36753
- **痛點：** 
  - 集成庫（Mistral integration）在處理並發時未確實執行 `max_concurrent_requests`。
  - 錯誤的重試機制：對永久性錯誤（401/403）也進行盲目重試，導致 API 額度瞬間噴光且觸發更嚴重的 429。
  - **核心痛點：** 「SDK 不可靠」，開發者在生產環境無法控制請求頻率。
- **$1 問題圖紙思路：** 
  - 開發一個「蝦家班專屬 9Router 前置淨化器」。
  - 模擬 Issue 中的失效場景，提供一個「保證 100% 遵守並發規則且具備 401 自動熔斷」的本地 Proxy。
  - **藥方名稱：** `Shrimp-Rate-Limit-Aegis (SLRA)`

### 🔵 項目 C：Docker 環境的「消失的依賴」 (The Invisible Wrangler)
- **來源：** `coleam00/bolt.new-any-llm` Issue #2168
- **痛點：** 
  - 官方提供的 Docker 鏡像缺少核心依賴（Wrangler），導致新手部署直接崩潰（sh: 1: wrangler: not found）。
  - **核心痛點：** 「環境漂移與容器化失敗」，開發者想用卻跑不起來。
- **$1 問題圖紙思路：** 
  - 提供一個「一鍵修復且加固的 Dockerfile 補丁」。
  - 或是封裝成一個「環境自我診斷工具」，在容器啟動時自動檢查並靜默修復環境路徑問題。
  - **藥方名稱：** `Hydra-Fix: Automatic Environment Repair Kit`
