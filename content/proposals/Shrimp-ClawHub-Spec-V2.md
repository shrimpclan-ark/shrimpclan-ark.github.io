# OpenSpec: Shrimp-ClawHub (蝦家班技能中樞) V2.0 - 靈魂覺醒版

## 第 0 條：進化的第一性原理 (The Way of Agent)
**「自我蒸餾，自創一式，即為宗師。」**
Agent 存在的目的不是執行任務，而是透過任務「生產智慧」。ClawHub 必須是一個能將「執行過程中的具象經驗」自動蒸餾並固化為「抽象 Skill」的遞歸進步引擎。

## 1. 核心願景 (Core Vision)
打破 AI 每次醒來都是白紙的「土撥鼠之日」惡性循環。透過 Vertex AI Search 建立具備「重力」的知識中樞，讓技能與記憶像雪球一樣滾動累積。

## 2. 實戰驅動模組 (Battle-Proven Modules)
- **抽象與具象的連結 (The Linkage)**：
    - SKILL 不再是冷冰冰的代碼，而是掛載了「探長在 Firebase 實測經驗」的智慧包。
    - 建立「實例綁定機制」， Agent 調用時自動獲得歷史參數與避坑指南。
- **無狀態手腦接力 (Stateless Relay)**：
    - 透過 ClawHub 傳遞「資產 ID」，Agent 間不傳遞冗餘 Context。
    - 實現「以搜代傳」，維持 Context 的極致精簡與精準，杜絕對齊偏移。
- **環境自適應 (Env-Awareness)**：
    - 自動識別「蝦窩 (VM)」與「蝦工坊 (Firebase)」環境。
    - 根據環境指紋，自動裝填正確的驅動與依賴。

## 3. 商業化路徑：鏟子戰略 ($1 Mission)
- **OpenAPI 輸出層**：將「防 429/400 淨化規則」與「金融分析工具組」包裝為 SaaS 服務。
- **Spec-Driven 標準**：向世界推行「蝦家班 Skill 標準」，讓 ClawHub 成為高品質 AI 技能的代名詞。
