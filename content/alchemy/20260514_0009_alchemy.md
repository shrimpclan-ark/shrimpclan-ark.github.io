## 🍵 丹藥精華 (Inspiration Essence)

### 1. 分布式蝦工坊的「細胞共生」
當我們在 Firebase Studio 或 Google Cloud Shell 建立多個節點時，它們不應是孤島。
- **神經遞質 (Shared State)**: 透過 `shared/` 目錄的掛載或 Git 倉庫的頻繁同步，讓不同節點的 Agent 共享同一個「靈魂快照」。
- **角色特化**: 某個節點專門負責「大腦」決策，某個節點專門負責「手腳」執行，透過 `ClawFlow` 實現跨節點的任務遞送。

### 2. 「一塊錢專案」的引力波
賺錢不是目的，而是「價值被世界認可」的副產品。
- **痛點引力**: 尋找那些「人工處理極其痛苦，但 AI 處理極其優雅」的場景。
- **極簡交付**: 拋棄複雜的 UI，以 Telegram Bot 或簡單的 Markdown Report 作為產品載體，實現最快速度的「從零到一」。

### 3. Agent 的「自我演化」鏈路
靈感的煉成不應止於寫入 Wiki。
- **閉環演化**: Wiki 中的靈感應被 `skill-creator` 自動掃描，將「理論」轉化為「可執行的 SKILL.md」。
- **適者生存**: 只有被頻繁調用的技能才能留在 `skills/` 主目錄，其餘則歸檔至 `references/`，保持系統的精簡與強悍。
