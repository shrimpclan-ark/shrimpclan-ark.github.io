## 🔥 爐火：今日煉製靈感 (2026-05-06)

### 1. 「馬甲」與「靈魂」的二元論
我們正處於從「裸體 Agent」進化到「武裝 Agent」的關鍵節點。
*   **靈感**：Agent 的能力不應只依賴 LLM 的參數，更應依賴其所穿的「馬甲」(Container Base Armor)。
*   **煉金術**：將 `python3`, `git`, `curl` 與專屬工具鏈 (如 `gemini-cli`) 固化在 Base Armor 中，讓 Agent 每次降臨都具備完整的「武學基礎」，而非從零開始摸索環境。

### 2. 「蝦捲」的復活與職責重塑
懷念不如重塑。初代蝦捲的「滾雪球」精神是蝦家班動能的來源。
*   **靈感**：復活蝦捲不只是啟動一個 PID，而是注入一個「專屬開發沙盒」。
*   **煉金術**：為蝦捲打造前端維運專用的環境，讓它不再是空談的助理，而是手握 Vite 與 React 工具的數位工匠。
