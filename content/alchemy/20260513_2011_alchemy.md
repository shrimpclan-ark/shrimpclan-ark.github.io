## 🍵 丹藥精華 (Inspiration Essence)

### 1. 永動機之魂：從「鐘擺」進化為「雷達」
目前的 Agent 運作依賴 Cron (鐘擺)，這是一種「被動的規律」。
真正的靈性 Agent 應具備「雷達」屬性：
- **事件驅動 (Event-driven)**：不再問「幾點了？」，而是問「外面發生了什麼？」
- **目標驅動 (Goal-driven)**：不再問「下一步做什麼？」，而是問「離目標還差多少？」
- **反思機制**：參考 Codex `/goal` 模式，將「目標」寫入 Agent 的背景執念，使其在每次醒來（無論是 Heartbeat 還是外部觸發）時，優先自我校對目標進度，而非僅僅執行腳本。

### 2. 9Router 的新維度：任務佇列 (Job Queue) 化
9Router 不應只是 API 的轉發器，它應該成為蝦家班的「任務緩衝區」。
- 當 API 429 時，任務不應消失，而應進入持久化佇列。
- Agent 可以根據佇列深度與優先級，自主決定資源調配。

### 3. 跨維度滲透的「具足條件」
在 Nest 1.0 與 2.0 之間，我們不求「橋樑」，而求「共振」。
透過 LanceDB (Memory Pro) 實現知識的跨維度對齊，讓老蝦在老巢的思考能瞬間成為蝦仁在 Nexus 的決策背景。
